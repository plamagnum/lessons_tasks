# 📚 Шкільна система тестування

Fullstack веб-застосунок для проведення тестів з різних предметів у школі (5–11 класи).

**Стек:** Nginx · PHP 8.2 · MySQL 8.0 · PhpMyAdmin · Docker Compose · Vanilla JS

---

## 🚀 Швидкий старт

### 1. Передумови
- [Docker](https://docs.docker.com/get-docker/) ≥ 24
- [Docker Compose](https://docs.docker.com/compose/) ≥ 2.20

### 2. Клонування та налаштування
```bash
git clone https://github.com/plamagnum/lessons_tasks.git
cd lessons_tasks
cp .env.example .env
# За бажанням змініть паролі в .env
```

### 3. Запуск
```bash
docker compose up -d
```
Перший запуск займає ~2 хвилини (завантаження образів та ініціалізація БД).

### 4. Перевірка
| Сервіс       | URL                        |
|--------------|----------------------------|
| Застосунок   | http://localhost            |
| PhpMyAdmin   | http://localhost:8080       |

**Логін адміна:** `admin` / `admin123`

## 📋 Функціонал

### Система оцінювання
- **12 запитань:** оцінка = кількість правильних відповідей (0–12)
- **24 запитання:** оцінка = кількість правильних / 2 (0–12)

### Призначення тестів
- **Всьому класу** — одночасно для всіх учнів класу
- **Індивідуально** — конкретному учню

### Проходження тесту
- 4 варіанти відповіді на кожне питання
- Після вибору: ✅ правильна підсвічується зеленим, ❌ неправильна — червоним
- Після здачі — детальний аналіз відповідей

## ⚙️ Адмін-панель

### Додати клас
1. Увійдіть як `admin / admin123`
2. Вкладка **Класи** → **+ Додати клас**
3. Введіть назву (напр. `10-А`) та номер класу (5–11)

### Додати предмет та тему
1. Вкладка **Предмети** → **+ Додати предмет** (напр. `Математика`)
2. Вкладка **Теми** → **+ Додати тему** → оберіть предмет

### Додати запитання вручну
1. Вкладка **Запитання** → **+ Додати запитання**
2. Оберіть тему, введіть текст запитання, 4 варіанти та правильну відповідь

### Імпорт запитань з JSON
1. Вкладка **Запитання** → **📥 Імпорт JSON**
2. Вставте JSON масив формату:
```json
[
  {
    "topic_id": 1,
    "question_text": "Скільки градусів у прямому куті?",
    "option_a": "45",
    "option_b": "90",
    "option_c": "180",
    "option_d": "360",
    "correct_option": "b"
  }
]
```

### Створити та призначити тест
1. Вкладка **Тести** → **+ Створити тест** → оберіть тему та кількість запитань (12 або 24)
2. Натисніть **📋 Призначити** → оберіть клас або учня

## 🔍 Парсери

### PHP парсер
```bash
cd parsers/php
php parser.php site1 https://example-edu.ua/math/algebra
```

Результат зберігається у `parsers/php/output/questions_site1_*.json`

**Як налаштувати під новий сайт:**
1. Відкрийте `parsers/php/config.php`
2. Скопіюйте блок `site1` і задайте нову ключову назву
3. Замініть XPath-селектори відповідно до структури HTML нового сайту
4. Встановіть `topic_id` відповідно до вашої БД

### Python парсер
```bash
cd parsers/python
pip install -r requirements.txt
python parser.py site1 https://example-edu.ua/math/algebra
```

**Як налаштувати під новий сайт:**
1. Відкрийте `parsers/python/parser.py`
2. Знайдіть словник `SITES`
3. Скопіюйте блок `site1` і задайте нову ключову назву
4. Замініть CSS-селектори та `topic_id`

### Імпорт результату парсера в систему
```bash
curl -X POST http://localhost/api/questions/import \
  -H "Authorization: Bearer <токен_адміна>" \
  -H "Content-Type: application/json" \
  -d @parsers/php/output/questions_site1_*.json
```

## 📁 Структура проекту

```
├── docker-compose.yml      # Сервіси Docker
├── .env.example            # Шаблон змінних середовища
├── nginx/nginx.conf        # Конфігурація Nginx
├── php/Dockerfile          # PHP 8.2-FPM образ
├── mysql/init.sql          # Схема БД та початкові дані
├── src/
│   ├── api/                # REST API (PHP)
│   │   ├── auth/           # Реєстрація / вхід
│   │   ├── classes/        # CRUD класів
│   │   ├── subjects/       # CRUD предметів
│   │   ├── topics/         # CRUD тем
│   │   ├── questions/      # CRUD запитань + JSON імпорт
│   │   ├── tests/          # CRUD тестів + призначення
│   │   ├── student/        # API для учнів
│   │   └── users/          # Управління учнями (адмін)
│   └── public/             # Фронтенд (HTML/CSS/JS)
│       ├── index.html
│       ├── css/style.css   # Темна/світла тема
│       └── js/
│           ├── app.js      # Роутер та ініціалізація
│           ├── api.js      # HTTP клієнт
│           ├── auth.js     # Стан автентифікації
│           ├── quiz.js     # Проходження тесту
│           └── admin.js    # Адмін-панель
└── parsers/
    ├── php/parser.php      # PHP парсер (DOMDocument + XPath)
    └── python/parser.py    # Python парсер (BeautifulSoup4)
```
